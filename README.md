# Blog App

Blog App is a simple blog application built with Django. It allows users to view blog posts. The project aims to provide a minimal yet extendable blog system that anyone can use

## Features

- View a list of available blog posts
- View details of individual posts
- Simple and clean UI with Bootstrap CSS

## Installation

### Clone the Repository

```sh
git clone https://github.com/cleven12/blog_app.git
```
